## 为什么没有伪造 Git 历史

旧账号和旧提交目前无法作为完整可访问的上游历史。为了避免把重建结果冒充原始提交，本仓库采用：

- `docs/history/DAILY_LOG.md`：按日期汇总源码、产物和备份；
- `docs/history/VERSION_HISTORY.md`：将每个本地发布/测试节点编号为 `Rxxx`；
- `docs/history/EVIDENCE_INDEX.md`：列出材料类型、数量和限制；
- `tools/Generate-ReconstructedHistory.ps1`：公开生成方法。
